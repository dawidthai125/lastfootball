## 4. Definition of Done — Reference Board

Board = **COMPLETE** gdy:

1. Wszystkie **16** pozycji mają status ≥ `APPROVED` (lub `APPROVED` z max 2 SOFT łącznie na boardzie, nie na DNA 1/5/8/10)  
2. REF-16 Family Strip PASS  
3. Consistency Gate per pozycja (Quality Checklist) PASS  
4. `LF-REF-BOARD-FOUNDATION-vN` złożony  
5. Style Lock Certificate podpisany (Style Lock §3)  
6. Visual DNA oznaczone `LOCKED`  

**Dopiero wtedy** wolno otworzyć `LFE-WORLD-ART-04`.
