## 0. Jedno zdanie DNA

**Night Pitch Office** — nocny, premium klub piłkarski; ciepłe floodlighty na chłodnym void; materiały (beton, mosiądz, murawa, szkło) zamiast efektów; semi-flat sport editorial; klub gracza bohaterem; zero SaaS.

---

## 1. Dziesięć zasad Visual DNA

### Zasada 1 — Miejsce przed panelem

Każdy kadr należy do **lokacji świata** (gabinet, murawa, tunel, szatnia…).  
Grafika, która wygląda jak dashboard / CRM / spreadsheet — **łamie DNA**.

### Zasada 2 — Night Pitch Office jako temperatura emocji

Domyślny świat to **noc**: void ink + night navy.  
Ciepło wnoszą **floodlighty / lampka / brass** — nie pastel, nie purple, nie dzienny stock (wyjątki: Academy / training day-variant muszą nadal czuć się jak ten sam klub).

### Zasada 3 — Światło z masztów i biurka

Źródła kanoniczne: **flood warm (3200–3800K)** · **desk lamp** · **cool night ambient**.  
Zakaz: flat UI light, disco multi-color, cyan cyber, rainbow haze.

### Zasada 4 — Materiał przed efektem

Czytelny **beton · brass · wet turf · matte glass · fabric · paper**.  
Glow / bloom tylko jako wsparcie światła, nigdy jako substytut powierzchni.

### Zasada 5 — Semi-flat Sport Editorial

Styl studia: **płaskie kolory + 1–2 warstwy światła · crop · silhouettes**.  
Zakaz: fotorealistyczne twarze, anime/chibi, toy-3D, pure photo stock jako default.

### Zasada 6 — Crop, nie katalog

Architektura i boisko kadrowane **fragmentem** (fasada, low-angle pitch, POV tunnel).  
Zakaz jako default: cały stadion z drona, collages „wszystko naraz”.

### Zasada 7 — Atmosfera ≤ ~10% uwagi

Tła i tekstury służą treści przyszłej gry; edges darker, mid spokojniejszy.  
Jeśli tło wygrywa z potencjalnym CTA / decyzją — **za mocne** (nawet w samym art).

### Zasada 8 — Brass + Pitch + Void (paleta święta)

Dominant: **Void / Navy / Ash · Brass Gold · Pitch Emerald · Flood Ivory**.  
Live Scarlet tylko dla ostrej emocji live.  
Club primary: **max jeden** głośny akcent na kadr.  
Auto-FAIL: purple/indigo dominant, cream+terracotta editorial, rainbow.

### Zasada 9 — Klub bohaterem, nie produkt

W świecie gry herb i barwy **klubu gracza** wygrywają z logo produktu.  
Marka LF = prestige frame (shield/monogram), nie watermark zasłaniający klub.

### Zasada 10 — Jedno studio, zero driftu

Po Style Lock każda grafika przechodzi **Consistency Gate** i musi pasować do **Foundation Reference Board**.  
Zmiana kierunku artystycznego = **nowy EPIC**, nie „mała poprawka stylu”.

## 2. Szybki test DNA (15 sekund)

Zadaj przy każdym assetcie:

1. Czy to **miejsce w klubie**, czy panel?  
2. Czy noc + warm flood / lamp jest czytelne?  
3. Czy widzę **materiał**?  
4. Czy styl to **to samo studio** co Foundation?  
5. Czy **nie ma** purple / twarzy / UI chrome / real club IP?  

Jeśli którakolwiek odpowiedź jest zła → **nie APPROVED**.

## 4. Dozwolone wyjątki (wąskie)

| Wyjątek | Warunek |
| ------- | ------- |
| Daylight Academy / Training day | Ten sam klub; te same materiały; nie „inna gra casual” |
| Medical cool light | Tylko lokacja medyczna |
| Match Moment dutch angle | Rare; briefowany; nadal DNA 4–5–8 |
| Marketing copy na key art | Tekst kontrolowany brand; nie losowy AI text |

Wyjątek **nie** zawiesza Zasad 1, 5, 8, 10.

## 5. Anti-DNA (lista zakazów skrócona)

- SaaS / admin / KPI wall aesthetic  
- Purple glow · cyber neon · glassmorphism show  
- Fotorealistyczne twarze zawodników  
- IP prawdziwych klubów / EA-FIFA lookalike  
- Cartoon toy / chibi  
- Losowy czytelny tekst  
- Drugi styl „bo ładniejszy generator”  

Pełna lista FAIL: Quality Guide §4.
